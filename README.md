
# N3XR Engine

Experimental Rust-based 3D block game engine.

## Version
0.2.0

## Technology
- Rust
- OpenGL ES 3.0
- Android NDK
- EGL

## Features
- Native engine foundation
- OpenGL ES 3 renderer
- Shader compilation
- Triangle rendering test
- Renderer lifecycle API
- Block and chunk foundation

## Android Targets
- armeabi-v7a
- arm64-v8a
